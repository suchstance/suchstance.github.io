Why I Have A Static Website

The World Wide Web was built as a way to manage information. An elegant design containing URLs, HTTP and HTML. That was all you needed to open any page on the internet, using a device that can access it. Much like our minds, we can hop between topics connected by links and browse down rabbit holes as much as we can. It’s simple enough for many people to build their own page and express themselves without bureaucracy.
