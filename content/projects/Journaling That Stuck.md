I have started and quit journaling more times than I can remember. I have an array of partially filled diaries, notes, accounts with Evernote and OneNote just to get things written down.

I finally tried Obsidian and found so much success with it. Because, now I have a journal I can customize the hell out of and design it to the way  **I** think.

I use Obsidian to capture, record and store information with a goal of creating a self-hosted, private repository of files that are relevant to my life. I use Obsidian Web Clipper extensively along with iOS shortcuts to extract and structure information from the web into Markdown files that are saved into my Obsidian Vault. If any of these are useful for you, browse this repo on github: [Structured Capture of Information I Consume](https://github.com/suchstance/ss_obsidian/tree/main)


Inspired from [kepano's repo](https://github.com/kepano/clipper-templates)

<h3> Schema-based templates: Extracts page variables using schema.org JSON-LD </h3> 

1. [Recipes](https://github.com/suchstance/ss_obsidian/blob/main/clipper_templates/recipes) gets you the cook time and list of ingredients in a clean markdown file
2. [IMDB](https://github.com/suchstance/ss_obsidian/blob/main/clipper_templates/imdb.json) creates a note with movie metadata and a space to add your own rating

<h3> Trigger templates from the website name </h3>

1. [Board Games](https://github.com/suchstance/ss_obsidian/blob/main/clipper_templates/board-game-bgg.json) captures new games I've played
2. [Goodreads](https://github.com/suchstance/ss_obsidian/blob/main/clipper_templates/goodreads.json) extracts book ratings and tags them to a nested genre taxonomy
3. [Wikipedia](https://github.com/suchstance/ss_obsidian/blob/main/clipper_templates/wikipedia.json) clips the first paragraph of articles I want to save
